三、类别名称

   0：成熟（成熟番茄）
   1：不成熟（未成熟番茄）

类别判定规则：
  呈现明显红色的番茄标注为成熟类；其余外观样本统一划分为不成熟类。
  对于橙色、橙黄色以及橙红过渡区间、类别边界较为模糊的番茄，统一归为成熟类别进行标注。


四、标注工具

使用 LabelImg 进行手动标注，开启 YOLO 格式保存。


五、标注格式

标注格式为 YOLO txt 格式：
   每张图片对应一个同名 .txt 标注文件

示例：
  0 0.512 0.487 0.234 0.312
  1 0.233 0.612 0.156 0.201


六、数据划分方法

数据集按 训练集 : 验证集 : 测试集 = 70 : 15 : 15 的比例划分。
各子集数量：
  - 训练集（train）：70 张
  - 验证集（val）：15 张
  - 测试集（test）：15 张
  - 总计：100 张

划分后的目录结构：
tomatoes_dataset/
├── images/
│   ├── train/    （训练集图片）
│   ├── val/      （验证集图片）
│   └── test/     （测试集图片）
└── labels/
    ├── train/    （训练集标注）
    ├── val/      （验证集标注）
    └── test/     （测试集标注）


七、标注过程中发现的问题

1. 部分图片中番茄有遮挡（叶子、枝干挡住一部分），框选时只能标可见部分，可能影响检测精度。
2. 成熟和不成熟的番茄在颜色上过渡不明显，有些半红半绿的番茄归类时存在主观性。
3. 番茄大小差异较大，近处的番茄占画面比例很高，远处的很小，小目标检测会有难度。
4. 光照不均匀，有些图片过亮或过暗，番茄颜色和背景对比不强，容易漏标。
5. 数据集整体数量不多（共100张），类别也只有2类，后续如果要提升模型效果需要补充更多样本。
