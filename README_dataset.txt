数据集说明文档


一、数据集简介

本数据集为番茄图像检测数据集，用于目标检测任务。
原始图片存放路径：D:\Deeplearning\make_dataset\tomatoes_dataset\images
划分后数据集路径：D:\Deeplearning\ultralytics-8.3.163\datasets\tomatoes_dataset


二、类别名称

成熟
不成熟

三、标注工具

使用 LabelImg 进行手动标注。
标注时开启 YOLO 格式保存，每张图片对应一个同名的 .txt 标注文件。


四、标注格式
标注格式为 YOLO 格式：

   每张图片对应一个同名 .txt 文件
 
   class_id 从 0 开始，对应上面的类别顺序

示例（单类别）：
  0 0.512 0.487 0.234 0.312


五、数据划分方法

数据集按 训练集 : 验证集 : 测试集 = 7 : 2 : 1 的比例随机划分
划分后的目录结构如下：

tomatoes_dataset/
├── images/
│   ├── train/    （训练集图片）
│   ├── val/      （验证集图片）
│   └── test/     （测试集图片）
└── labels/
    ├── train/    （训练集标注）
    ├── val/      （验证集标注）
    └── test/     （测试集标注）


六、标注过程中发现的问题

1. 部分图片中番茄有遮挡（叶子、枝干挡住一部分），框选时只能标可见部分，可能影响检测精度。
2. 番茄大小差异较大，近处的番茄占画面比例很高，远处的很小，小目标检测会有难度
3. 光照不均匀，有些图片过亮或过暗，番茄颜色和背景对比不强，容易漏标
4. 标注时框的松紧程度不一致，不同图片之间框的贴合度有差异，后续训练前可以再统一检查一遍
5. 数据集整体数量不算很多，类别也比较单一，后续如果要提升模型效果需要补充更多样本
6. 将呈现明显红色的样本标注为成熟类；其余外观样本统一划分为不成熟类 针对橙色、橙黄色以及橙‑红色
过渡区间、类别边界较为模糊的番茄样本，统一归为成熟类别进行标注
